Mode d'emploi

AUTO_RCI génère automatiquement des fiches Word RCI, RE ou PV à partir d'un fichier Excel de mesures. L'application insère les valeurs, les images et les courbes, puis enregistre les documents dans le dossier du lot (LT).

Ce guide est destiné aux utilisateurs au quotidien. Pour les détails techniques (tags, architecture, code), voir DOCUMENTATION_TECHNIQUE.html.

Prérequis

ÉlémentPourquoi
Windows 10/11L'application est conçue pour Windows.
Microsoft ExcelLecture des mesures et export des courbes (pilotage automatique).
Microsoft WordOuverture du modèle et génération des fiches.
Python 3.9+Installé une fois par poste (ou via le dossier réseau partagé).
Accès réseauDossiers HOI/LT, fichier mesures, modèles de formulaires.
Fermez Excel et Word ouverts manuellement avant de lancer une génération — sinon le pilotage automatique peut échouer.

Première installation (une fois par poste)

  1. Ouvrir le dossier AUTO_RCI_COMPLET sur le réseau (ex. X:\Production\4_Public\DEV (ne pas toucher)\AUTO_RCI_COMPLET).
  2. Double-cliquer sur install_modules.bat — installe les modules Python et Poppler (conversion PDF → image) dans tools/poppler/.
  3. Attendre la fin sans fermer la fenêtre. En cas d'erreur, vérifier que Python est dans le PATH Windows.
  4. Créer un raccourci bureau vers lancer_RCI.bat (clic droit → Envoyer vers → Bureau).
Poppler s'installe automatiquement — aucun chemin à configurer manuellement sur chaque PC.

Lancer l'application

Double-cliquez sur lancer_RCI.bat. La fenêtre Auto RCI s'ouvre avec 4 onglets en haut.

Panneau de droite (récapitulatif) :
  dossier de lancement (LT)
  fichier Excel des mesures
  fichier formulaire (modèle Word)
La configuration est mémorisée dans config/paths.json et config/fields.json. Elle est rechargée à chaque ouverture.

Les 4 onglets

1 — Find Data (remplissage automatique)

ChampAction
LTSaisir le numéro de lancement, ex. LT2501492.
FormulaireSaisir le formulaire, ex. F487 D (numéro + indice).
CatégorieChoisir RE, PV ou RCI — définit le dossier de sortie.
Bouton fillRecherche automatiquement le dossier LT, le fichier mesures et le modèle Word sur le réseau.

2 — Paths (chemins manuels)

Si le remplissage auto échoue, configurez les chemins à la main :

BoutonContenu à sélectionner
choix chemin mesuresFichier Excel, ex. mesures HOI 25.008A.xlsx
choix chemin formulaireModèle Word (.docx) du formulaire
choix chemin lancementDossier du LT, ex. …/RETA-697-HOI-25.008/LT2501492
choix chemin PopplerEn principe inutile — laisser vide ou le chemin auto tools/poppler/

3 — Générateur fiches RCI/RE

ÉlémentRôle
format du nom de fichierModèle du nom généré, ex. **REF_SEDI**_SN**SN**_RCI
chemin de sortieSous-dossier dans le LT, ex. RCI, PV ou RE
réaction aux fichiers préexistantsconserver / dupliquer / remplacer / demander
générer documentLance la génération (voir procédure ci-dessous)
oui / nonRépondre aux questions pendant la génération (ouvrir dossier, etc.)

4 — Conversion PDF

Convertit en lot les fichiers Word/Excel d'un dossier en PDF (filtre par texte dans le nom). Indépendant de la génération des fiches.

Procédure type — générer des fiches

  1. Renseigner le LT et le formulaire Onglet Find Data → saisir LT + formulaire + catégorie (RCI/RE/PV) → cliquer fill. Vérifier le panneau de droite : les 3 chemins doivent s'afficher en vert.
  2. Vérifier les chemins Si un chemin est manquant, aller dans l'onglet Paths et le sélectionner manuellement.
  3. Configurer la sortie Onglet Générateur fiches RCI/RE → vérifier le dossier de sortie (RCI, PV…) et le format du nom de fichier.
  4. Lancer la génération Cliquer générer document. Choisir :
    → Option 1 : tous les SN du LT
    → Option 2 : sélection manuelle des numéros de série
  5. Attendre la fin Suivre les messages dans la zone de log. L'indicateur passe de « en cours » à « --- ».
  6. Récupérer les fichiers Les documents sont dans :
    {dossier LT}/{chemin de sortie}/
    Ex. …/LT2501492/RCI/. Répondre oui pour ouvrir le dossier automatiquement.
Le LT est aussi détecté automatiquement depuis le chemin du dossier de lancement. Le numéro de plan est déduit du nom du fichier mesures ou du chemin HOI.

Comprendre les fichiers générés

CasSignificationQue faire
Fichier normal Tous les tags remplis, images et courbes trouvées. Rien — document complet.
…[INCOMPLET].docx Donnée, image ou courbe manquante. Consulter les logs (Logs/) et corriger le dossier LT ou l'Excel.
Fichier dupliqué Mode « dupliquer » actif et fichier déjà existant. Un suffixe est ajouté au nom — vérifier le bon exemplaire.

Où sont les logs ?

Dossier Logs/ à la racine de l'application. Fichiers problems, normal et verbose selon le niveau de détail.

Préparer ses dossiers (bonnes pratiques)

Structure attendue du dossier LT

LT2501492/ ← dossier de lancement (root_work_dir)
├── RCI/ ← sortie fiches RCI
├── PV/ ← sortie procès-verbaux
├── RE/ ← sortie rapports d'essai
├── DICHRO_GRAND_CHAMP/ ← images dichro (exemple)
│   └── SN25-20-07.JPG ← nom contenant SN + numéro
├── test pression/ ← courbes Excel (exemple)
│   └── courbe SN25-20-07.xlsx
└── …
RègleDétail
Images Nom du fichier doit contenir SN{numéro}, ex. SN25-20-07.JPG (majuscules ou minuscules).
Courbes Excel Légende du graphique au format S/N{numéro} pour l'export automatique.
Fichier mesures Le LT saisi doit exister dans l'Excel — sinon « Aucun SN trouvé ».
Modèle Word Tags **NOM** pour le texte, §§DOSSIER§§ pour les images du sous-dossier correspondant.

Conversion PDF (onglet dédié)

  1. Choisir le répertoire contenant les Word/Excel à convertir.
  2. Renseigner les filtres — texte obligatoire dans le nom, texte à exclure.
  3. Options — cocher « convert excel files » et « Remplacer les PDF existants » si besoin.
  4. Cliquer convertir en pdf — les PDF sont créés à côté des fichiers source.

Dépannage rapide

ProblèmeSolution
Python introuvable Réinstaller Python 3.9+ avec « Add to PATH », relancer install_modules.bat.
Aucun SN pour le LT Vérifier que le bon fichier mesures est sélectionné et que le LT existe dans l'Excel.
Formulaire non trouvé Vérifier le format Fxxx A et l'accès au dossier formulaires réseau.
Images non insérées Vérifier le nom SN…, l'extension (.JPG acceptée), le sous-dossier référencé dans le tag Word.
Courbes Excel absentes Fermer Excel, vérifier la légende S/N…, relancer la génération.
Config écrasée par un collègue Sur un dossier réseau partagé, le dernier utilisateur écrase config/ — reconfigurer via Find Data.
Raccourci bureau ne marche pas Le raccourci doit pointer vers lancer_RCI.bat sur le réseau, pas une copie locale obsolète.
Vérifier l'installation — lancer tests_terrain\lancer_demo_tests.bat (8 succès + 5 échecs volontaires = OK). Voir documentation des tests.
