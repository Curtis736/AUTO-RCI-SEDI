AUTO_RCI_COMPLET

Application Windows (Python / Tkinter) qui génère des fiches RCI / RE / PV en Word à partir d'un fichier Excel de mesures, avec insertion d'images, courbes Excel et graphiques dichroïques.

Installation (une fois par poste ou sur le dossier réseau partagé)
1. Exécuter install_modules.bat (modules Python + Poppler dans tools/poppler/)
2. Lancer lancer_RCI.bat
Mode d'emploi utilisateur — MODE_EMPLOI.html (ou double-clic sur ouvrir_mode_emploi.bat) : procédure pas à pas, onglets, dépannage.
Configuration utilisateur — onglet Paths : fichier mesures, modèle Word, dossier de lancement (LT). Valeurs enregistrées dans config/paths.json et config/fields.json.

Architecture

src/Interface.py → point d'entrée (lancer_RCI.bat) ├── PathsInterface → chemins (mesures, modèle, LT) ├── FieldFillerInterface → auto-remplissage depuis LT ├── DocumentGenerator → génération des fiches │ ├── ValueFetcher → lecture Excel → Container par SN │ ├── Writer → remplacement tags Word + images │ ├── CustomImageTagProcessor → tags §§...§§ │ ├── ExcelController → COM Excel (courbes, dichro) │ └── ImageReader → cache images, PDF→PNG ├── PdfGenerator → conversion PDF par lot ├── poppler_setup → installation auto Poppler └── Settings / Log / FileFinder

Flux de génération

  1. Charger la config — chemins mesures, modèle, dossier LT.
  2. Lire Excel — ValueFetcher.FetchValuesInExcel() crée un container par SN.
  3. Choisir les SN — tous ou sélection manuelle.
  4. Ouvrir le modèle Word — Writer.Open().
  5. Remplacer les tags texte — **TAG** (texte), $$TAG$$ (colonnes tableaux).
  6. Insérer images et courbes — tags §§DOSSIER§§, fichiers JPG/PNG/PDF/XLSX dans les dossiers du LT.
  7. Sauvegarder — dans {root_work_dir}/{generator_out_path}/. Suffixe [INCOMPLET] si données ou images manquantes.

Tags du modèle Word

FormatUsage
**TAG**Valeur texte lue dans le fichier Excel de mesures.
$$TAG$$Colonne de tableau (séries de mesures).
§§NOM_DOSSIER§§Images du dossier {root_work_dir}/NOM_DOSSIER/ dont le nom contient le SN (JPG, PNG, PDF, XLSX).
§§NOM_DOSSIER_01§§Même principe avec filtre ou index (_01, _02…).
§§DICHRO_GRAPH§§Graphique dichroïque exporté depuis le classeur « Suivi traitement » (recherche auto).
Les courbes Excel dans un dossier §§...§§ sont exportées via COM Excel (légende S/N{SN}). Les PDF passent par Poppler (tools/poppler/, installé automatiquement).

Tests

Deux lanceurs dans tests_terrain/, sur un vrai LT du dossier test-unitaire/ (profil dans lt_profile.json).

Documentation détaillée : tests_terrain/DOCUMENTATION_TESTS.html — catalogue des tests, profil LT, dépannage.
tests_terrain/
├── DOCUMENTATION_TESTS.html   ← documentation complète des tests
├── lancer_tests_terrain.bat   ← suite complète (unitaires + LT réel)
├── lancer_demo_tests.bat    ← démo succès puis échecs volontaires
├── lt_profile.json           ← LT de référence (ex. LT2400182)
├── test_lt_reel.py           ← tests terrain sur données réelles
├── test_demo_succes.py      ← 8 tests qui doivent réussir
└── test_demo_echec.py       ← 5 tests qui doivent échouer (démo)
ScriptUsage
lancer_tests_terrain.bat Lance tests/unit/, test_lt_reel.py et l'intégration. La config utilisateur est sauvegardée puis restaurée.
lancer_demo_tests.bat Étape 1 : test_demo_succes.py (tout doit passer). Étape 2 : test_demo_echec.py (tout doit échouer — c'est normal).

Étape 1 — tests qui réussissent

Vérifient : profil LT, fichier mesures, dossier LT, extraction LT, image SN réelle (SN25-20-07.JPG), normalisation LT, config Settings.

Étape 2 — tests qui échouent (volontairement)

Simulent : fichier mesures inexistant, LT LT9999999 absent d'Excel, SN 99-99-99 sans image, dossier LT fictif, comparaison LT incorrecte.
Si ces tests passent, la détection d'erreurs ne fonctionne plus.

Points d'attention

Windows + Microsoft Office requis. Excel et Word sont pilotés via COM (pywin32).
Poppler automatique. Installé dans tools/poppler/ par install_modules.bat ou au premier lancement. Aucune config manuelle par poste.
Fichier [INCOMPLET] — tag non rempli, spec hors limites, image ou courbe manquante. Consulter les logs (Logs/).
Bonnes pratiques — fermer les instances Excel/Word ouvertes manuellement avant la génération ; noms d'images contenant SN{numéro} ; courbes Excel avec légende S/N{numéro}.
