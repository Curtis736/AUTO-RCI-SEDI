Documentation des tests

Cette page décrit comment lancer et comprendre les tests d'AUTO_RCI_COMPLET. Les tests terrain utilisent des données réelles dans test-unitaire/, pilotées par lt_profile.json.

Démarrage rapide

LanceurCommandeQuand l'utiliser
lancer_demo_tests.bat tests_terrain\lancer_demo_tests.bat Vérifier que la suite détecte les bons cas et les erreurs (démo rapide, ~5 s).
lancer_tests_terrain.bat tests_terrain\lancer_tests_terrain.bat Suite complète : unitaires + LT réel + intégration (~30 s à 2 min selon Excel).

Résultats attendus — démo

Étape 1 — test_demo_succes.py : 8/8 OK
Étape 2 — test_demo_echec.py : 5/5 échecs → message OK (demo valide)
Si l'étape 2 affiche des tests réussis, la détection d'anomalies est cassée — ne pas ignorer ce signal.

Prérequis

  1. Python 3 installé et accessible via python dans le PATH.
  2. Dépendances installées (install_modules.bat).
  3. Dossier test-unitaire/ présent avec les données de référence.
  4. Pour les tests Excel : Microsoft Excel installé (COM / pywin32). Sinon certains tests sont ignorés (skip).

Le dossier test-unitaire/ — ce n'est PAS les tests unitaires

Attention au nom : test-unitaire/ contient des données réelles de production (copies réduites), pas le code des tests. C'est un « bac à sable » qui imite la structure des dossiers HOI/LT sur le réseau.

NomC'est quoi ?
test-unitaire/ Données de test — Excel, images JPG, dossiers LT, comme en production.
tests/unit/ Code Python des tests unitaires (logique isolée, sans vrai LT).
tests_terrain/ Scripts qui lisent test-unitaire/ via lt_profile.json.

À quoi sert chaque type de fichier ?

ÉlémentRôle pour AUTO_RCI
mesures HOI …xlsx Source des valeurs (IL, RL, dates, opérateurs, numéros SN par LT). Lu par Excel COM.
LT2400182/ (dossier LT) Dossier de travail : sous-dossiers RCI, PV, RE, tests pression/hélium, etc. C'est root_work_dir dans la config.
SN25-20-07.JPG Photo dichroïque liée au SN. L'appli cherche SN{numéro} dans le nom du fichier.
DICHRO_GRAND_CHAMP/ Dossier d'images pour les tests de recherche SN (32 images dans LT2500543).

Comment lt_profile.json utilise ces données

Le profil de test assemble des morceaux de différents dossiers (comme en vrai quand plan et images ne sont pas au même endroit) :

Clé profilPointe versPourquoi
measurement_file RETA-697-HOI-23.199/mesures HOI 23.199.xlsx Tester la lecture Excel et la recherche SN pour LT2400182
root_work_dir RETA-697-HOI-23.199/LT2400182 Tester que le dossier LT existe et que le LT est extrait du chemin
image_folder LT2500543/DICHRO_GRAND_CHAMP Tester la recherche d'images (LT2500543 a des JPG complets)
sample_sn 25-20-07 SN connu présent dans les images (fichier SN25-20-07.JPG)
En résumé : test-unitaire/ = fausses données production pour tester l'appli sans toucher aux vrais dossiers réseau. Vous ne modifiez pas ce dossier au quotidien — seulement lt_profile.json si vous voulez pointer vers un autre LT.

Sauvegarde de la configuration

Les lanceurs ne laissent pas la config utilisateur modifiée après exécution.

  1. Avant les tests — copie de config/paths.json et config/fields.json vers config/_backup_avant_tests/.
  2. Pendant les tests — terrain_context.apply_profile_to_settings() injecte le profil LT de test.
  3. Après les tests — restauration automatique depuis la sauvegarde.
Si plusieurs personnes lancent des tests en parallèle sur le même partage réseau, éviter les chevauchements : la config est partagée.

Dépannage

SymptômeCause probableAction
Étape 1 démo en échec Données test-unitaire/ manquantes ou profil incorrect Vérifier chemins dans lt_profile.json, présence de mesures HOI …xlsx et images SN
Étape 2 démo : tests qui passent Logique de détection altérée dans le code Comparer avec test_demo_echec.py — ces tests doivent échouer
test_find_sn_from_lt_excel skip Excel non installé ou COM bloqué Installer Excel, fermer instances ouvertes, relancer
Aucun SN pour LT dans Excel LT du profil absent du fichier mesures Choisir un LT présent dans l'Excel ou mettre à jour measurement_file
Image SN introuvable Extension en majuscules ou SN incorrect Vérifier SN{sample_sn}.JPG dans image_folder
Python introuvable Python absent du PATH Windows Réinstaller Python avec « Add to PATH », ou utiliser le venv du projet
